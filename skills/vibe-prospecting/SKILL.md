# Vibe Prospecting (Explorium MCP)

Practical list-building and enrichment via the Vibe Prospecting remote connector — complementary to the strategy skills in this repo (e.g. outbound-prospecting, data-enrichment-integration).

## Setup

- Add remote MCP: `https://vibeprospecting.explorium.ai/mcp` ([vibeprospecting.ai](https://vibeprospecting.ai))
- Sign in with browser OAuth. Never paste API keys into chat.

## Workflow

1. **ICP intake** — people vs accounts; titles + seniority; industry, size, geo; optional tech/funding/hiring; count (default 25).
2. **Preview** — fetch ~5–10 sample rows; restate filters; wait for approval.
3. **Export** — materialize the approved audience; do not invent rows if the connector is offline.
4. **Enrich** — email before phone; firmographics/technographics on request; report fill rate.
5. **Handoff** — table/CSV for CRM or sequencer; pair with outbound-prospecting or copywriting skills for messaging.

## Guardrails

- Sample first; no fabricated emails/phones/firmographics.
- Honest gaps when matches are empty or filters are too broad.
- Prefer this skill for live data pulls; use methodology skills for strategy and conversation design.
